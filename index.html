Storage model

Private, backend-free demo data

CarCare stores demo records in this browser's localStorage. Records persist after refresh and browser restart, but they do not sync across devices, browsers, or Chrome profiles. Use Reset demo data any time to restore the seeded Toyota Sienna history.

Add Maintenance

Agent tools exposed by WebMCP

Instead of guessing which button to click, an agent can call explicit tools registered with document.modelContext.registerTool:

  • get_vehicle()
  • get_maintenance_history()
  • add_maintenance_record(service, mileage, date, notes)
  • edit_maintenance_record(id, service, mileage, date, notes)
  • calculate_next_service(service)
  • search_maintenance_records(query)
