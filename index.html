      Agent tools exposed by WebMCP

      Instead of guessing which button to click, an agent can call explicit tools registered with document.modelContext.registerTool:

      • get_vehicle()
      • get_maintenance_history()
      • add_maintenance_record(service, mileage, date, notes)
      • calculate_next_service(service)
      • search_maintenance_records(query)
